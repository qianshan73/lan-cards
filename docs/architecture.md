# 一起出牌：首版设计约定

## 产品边界

- Android / iPhone 安装同一个跨平台 App，均可前台创建房间。
- 每个设备同时只参与一个房间，每个房间同时只进行一局。
- 已有 Wi-Fi 或手机热点时使用局域网直连；不依赖外部账号或云端。
- 首页只有「创建房间」「搜索房间」两个主入口。手动地址是备用路径。
- 自动发现采用 DNS-SD/mDNS，Android NSD / iOS Bonjour；不是扫描全部 IP。
- 网页端、自动开热点、后台保活、AI 托管、主机迁移、旧主机进程恢复均不在首版范围。
- 第一版游戏是 2–6 人的轮流出牌测试模块，不冒充斗地主或21点。

## 分层

```
Flutter 界面
    ↓
AppController：页面、生命周期、重连协调
    ↓
DiscoveryService：发布 / 搜索服务 + HTTP 房间概况
RoomClient：WebSocket、命令确认、本人恢复凭证
    ↓
RoomServer：连接绑定身份、广播各自的玩家视图
    ↓
Room：座位、权限、对局生命周期、操作去重
    ↓
GameRules：纯规则接口
    └─ RoundRobinRules：测试游戏
```

底层规则不依赖 Flutter；传输层不直接读写游戏内部手牌。房主自己的界面也通过客户端连接到主机，不使用 UI 特权捷径。

## 三个不同的实体

1. **成员身份**：随机 playerId + 私有 token。
2. **座位**：空 / 在线占用 / 离线保留。
3. **连接**：可关闭、可被同一身份的新连接替换，不等于退出房间。

昵称只是展示数据，不参与认证。断线不释放座位，不设离线处罚倒计时。只有明确离开、房主踢出或房间销毁释放座位。房主手动结束本局也不删除离线座位。

## 对局参与者与房间成员

开局时冻结本局参与者集合；新人有空位即可加入房间，但没有本局手牌，等待下一局。本局之外的成员离线不暂停当前牌局，也不计入本局自动恢复条件。

## 对局状态

```
大厅 ──全员在线、准备且满足人数──→ 进行中
进行中 ──本局参与者失联──→ 暂停
暂停 ──所有本局参与者恢复──→ 进行中
进行中 / 暂停 ──房主终止──→ 大厅（作废、不计分、座位保留）
进行中 ──规则判定结束──→ 已结束 ──重新准备──→ 下一局
```

房主失联：客户端停止操作、重试连接；可以自行退出。没有新房主接管。房主显式关闭时发送 `room_closed`；房主进程突然消失时客户端只能检测到失联，不能凭网络错误断言进程已经死亡。

## 重连

- 加入后把 roomId / playerId / token / 地址 / 房间名写入系统安全存储。
- App 启动优先尝试恢复原身份；原地址不可用时搜索同一 roomId。
- 恢复成功由主机下发最新完整的本人视图，不重放旧界面缓存。
- token 失效或原地址已经是另一个房间时清除恢复信息。
- 新连接替换旧连接，旧连接关闭回调不能把新连接错误地标记离线。
- 房主恢复凭证带 `isHost` 标识；冷启动不尝试凭本地回环地址复活旧房间。
- 不把完整牌局保存到磁盘。普通玩家 App 重启可恢复身份；主机重启不能恢复旧局。
- 返回首页可以保留恢复信息；放弃恢复后，若无法通知主机，需要房主手动释放原座位。

## 踢出与主动退出

主机按连接绑定的身份验证权限，拒绝消息中伪造的 actorId。房主踢出立即撤销成员与 token，释放座位；不能踢出自己，房主退出应关闭房间。

当前测试游戏的 `onDeparture` 跳过退出者；只剩一人时结束本局。未来斗地主等固定身份游戏必须实现自己的弃权 / 作废规则，公共框架不假设删除座位后一定能继续。

## 消息正确性

- 每次命令有随机 requestId，主机保留每位成员最近 256 次成功命令的去重记录。
- 每手牌有独立 roundId，旧局命令不能作用于新局。
- 主机单线程事件循环串行执行规则；不在执行规则过程中 `await`。
- 客户端不乐观修改手牌，等待主机状态。
- ack 只表示命令已经被主机接受；状态广播才是展示依据。客户端不盲目重放超时的出牌操作。
- WebSocket 心跳是内部连接检测，不是用户可见的离线处罚倒计时。

## 扩展新的游戏

实现 `GameRules` 的元信息、初始化、操作验证与应用、退出处理和玩家视图。随后注册规则，并增加对应的牌桌呈现。静态规则不依赖网络或 UI。

未来出现不同游戏生命周期时再扩展接口，首版不建设脚本平台或动态插件商城。

## 信任模型

- 主机保存完整牌局，所有玩家需信任房主设备。
- 对手手牌不发送给其他客户端，发现记录不包含恢复 token。
- 首版局域网 HTTP / WebSocket 为明文连接，不宣称抵御局域网窃听或恶意房主。TLS 身份配对可以作为后续独立改进。
- 无账号环境下，踢出撤销的是成员身份，不是不可伪造的硬件封禁。对方可以换身份申请空位；以后有需要再增加房间口令或房主批准。
- 限制握手时间、消息大小与同时连接数量；不记录恢复 token 或完整手牌到日志。

## 仍需真机验收

自动化 Socket 测试不代表 Android / iOS 原生发现已通过实机测试。必须覆盖同 Wi-Fi、Android 热点、iPhone 热点、两种房主方向、权限拒绝后恢复、热点提供者与游戏房主分离，以及主机进程结束。见 testing.md。
