# 局域网发现诊断（2026-10-30）

这是**已实现、已自动化测试的诊断能力**，不是 Android / iPhone 真机 Wi-Fi、Bonjour、NSD 或热点兼容性验收结果。

## 从哪里查看

- 搜索页直接展示发现状态、最近一次检查计数和下一步建议；刷新按钮可重试。
- 搜索、恢复座位、测试牌桌和斗地主牌桌均可打开「局域网诊断」。房间发布失败时入口显示橙色断网图标，不会因准备或出牌清除。
- 房主可在诊断面板「重新发布房间」，原有牌桌菜单入口仍保留。不重新创建房间、不影响座位或当前局。
- 「复制脱敏诊断」只在用户主动点击时写入系统剪贴板，无自动日志、持久化或上传。

## 如何判断

| 阶段 / 状态 | 含义与下一步 |
|---|---|
| DNS-SD 搜索未运行 / 启动中 / 已启动 / 失败 | 与房间发布分别记录；启动失败后可重新搜索 |
| 房间发布失败 | 房主本机房间仍可运行，但不代表朋友搜得到；允许权限后重新发布，必要时使用备用地址 |
| `permission` | 原生插件明确报告安全 / 权限问题；在系统设置允许本地网络权限后重试 |
| `unsupported` | 原生插件明确报告不支持；尝试备用地址，并记录设备和系统版本 |
| `busy` | 原生服务请求过多或重复运行；稍候重试 |
| `platform` | 原因不明确的原生错误；检查权限和网络后重试，不冒充精确的权限检测 |
| 未取得可用地址或端口 | 服务已经被发现，但解析失败 / 超时，或没有可尝试的主机地址与有效端口；请房主保持前台、重新发布，必要时尝试备用地址 |
| HTTP `timeout` / `network` | 服务有可尝试的端点，但房间检查超时或连接失败；确认房主在前台、同一网络，检查访客网络 / 热点隔离，重新搜索或换网络 |
| HTTP `httpStatus` | `/room` 没有返回成功状态（包括重定向）；确认房间仍开启后重试 |
| HTTP `invalidResponse` | JSON / UTF-8、协议或必要房间字段无效；双方使用相同版本 App 后重新开房 |
| HTTP `tooLarge` | 响应超过 8192 字节，停止读取；核对应用和版本 |
| 手动检查 `invalidEndpoint` | 输入的主机或端口不可用；核对房主显示的备用地址 |

「已启动」只表示发现启动调用成功；发布成功只表示注册调用成功。两者都不证明另一部手机可发现 / 可连接。发现零服务也不能断定不在同一个网络，更不能断定权限被拒绝。HTTP 检查成功不是加入成功、身份认证成功或重连恢复成功。

## 统计与实现边界

- 网络层 `lib/network/discovery_diagnostics.dart` 只提供固定枚举、计数和脱敏报告；`lib/ui/discovery_diagnostics.dart` 决定中文说明与操作，游戏规则层不参与。
- 关闭插件自动解析，保留原始服务可见性，再由发现服务显式解析，捕获解析错误而不是让服务在插件自动解析阶段丢失。服务自带可用端点时直接探测；已有成功解析结果仅在该服务仍存在且 HTTP 检查持续成功时复用。
- 每三秒刷新 HTTP 检查；单次最多检查 32 个服务，面板区分发现数与检查数。失败计数是最近一次完整检查的快照，不是累计失败日志；成功或服务消失后替换，停止搜索时清空。
- 手动地址探测使用同一套 HTTP 分类，但结果单独显示，不混入自动发现计数。HTTP 探测总时限默认 2 秒，不跟随重定向，限制响应体 8192 字节。
- 优先 IPv4，其次可尝试的 IPv6 / 主机名；过滤空地址、通配地址、组播和缺少接口作用域的 IPv6 链路本地地址。主机名被接受为可尝试端点，但后续 DNS / HTTP 仍可能失败。
- 停止 / 关闭后忽略旧异步结果；迟到的原生发现和注册资源尽力释放。服务变化若发生在检查期间，会合并触发下一次检查。
- 无新增在线诊断服务、网络拓扑检测、系统设置跳转、自动权限授予或后台保活。

## 隐私与真机记录

报告只有版本标记 `lan-discovery-v1`、搜索 / 发布状态、白名单失败类别、服务与房间计数。不包含 IP / 主机名 / 端口、服务名、TXT、房间 ID / 名称、玩家身份、重连 token、API Key、HTTP 响应体、原始异常或任何手牌。不要启用插件的原始调用 / 异常日志来替代该报告。

真机按 [testing.md](testing.md) 的网络矩阵分别记录：设备型号、系统版本、App 构建版本、网络类型、是否为热点提供者、权限操作顺序、能否发现、能否实际加入，以及双方的脱敏报告。若尝试备用地址，只记录是否成功，不把完整地址写进共享记录。不要提交系统日志、带手牌的截图或恢复凭证。

截至本记录日期：**全部真机矩阵仍未执行**。本机 HTTP / 测试替身通过，不能证明手机热点允许组播或客户端互通。当前 `dist/` 中的 0.2.0 APK 为本次修改之前的产物，尚不包含诊断功能；真机检查前需重新构建。
