# 经典斗地主 v1（0.2.0）

日期：2026-10-28，Asia/Shanghai。

## 玩法

三位真实玩家，各 17 张牌，另留 3 张底牌。无癞子，无叫分模式，无真钱、兑换或充值；积分只存在当前房间。

### 叫抢地主

1. 主机随机指定一位先叫，可选「叫地主 / 不叫」。
2. 有人叫地主后，未曾选择「不叫」的其他人按座位顺序「抢地主 / 不抢」。
3. 若其他人抢过，最初叫地主的人获得最后一次抢地主机会。
4. 最后一次有效叫 / 抢者成为地主，每次「抢地主」使当前倍数乘 2。
5. 三人都不叫时，主机重新洗牌发牌，并更新 roundId，旧叫牌操作不能落入新牌局。
6. 地主获得底牌，三张底牌向全员公开；地主先出。

### 出牌

- 点数：3 < 4 < … < K < A < 2 < 小王 < 大王；花色不比较大小。
- 支持单张、对子、三张、三带一、三带一对。
- 顺子至少 5 张；连对至少 3 对；飞机主体至少 2 组连续三张，均不能包含 2 或王。
- 飞机可以不带、带同数量单牌或同数量对子。
- 本项目的单翅膀可把一对当两张单牌，但不能同时带双王，不能把三张或炸弹作为单翅膀，不能使用主体点数作翅膀。
- 四带两单允许一对作两单，但不允许把双王作两单；四带两对要求两个不同点数的对子。
- 炸弹可压普通牌型；王炸最大。普通跟牌要求牌型和张数一致，主体点数更大。
- 两家连续不出后，最后出牌者重新领出，不能不出。

民间与不同商业版本存在翅膀、叫抢顺序等差异；这里是明确固定的一套常见规则，不宣称复制某商业游戏的全部模式。

### 胜负与积分

- 地主出完则地主获胜，任一农民出完则两名农民同时获胜。
- 底分为 1；每次抢地主、打出炸弹或王炸，倍数乘 2。四带二不当作炸弹翻倍。
- 地主胜且两位农民都没有出过牌：春天再乘 2。
- 农民胜且地主只出过一手牌：反春再乘 2。
- 地主输赢两份，农民各输赢一份，三人积分变化之和为 0；只结算一次。
- 房主「结束本局」作废、不计分、保留所有座位。
- 叫抢阶段主动退出或被踢出：本局作废。地主已确定后退出 / 被踢出：退出者所在阵营弃权，正常零和结算但不额外计算春天。
- 断线不是退出：占座、暂停、重连恢复，不自动弃权。

## 操作

- 全应用横屏；前台保持亮屏，不授予后台持续执行权限。
- 点击牌或横向划过多选，选中的牌抬起；出牌失败时保留选择供调整。
- 提示是纯本地的合法牌推荐，不是 AI 托管，不自动提交。
- 房主右上角设置可结束本局、踢人；暂停提示不遮挡这些操作。
- 结算后所有人重新准备，房主再开始；不重新加入房间。
